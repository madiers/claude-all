# Galtech Design Tools training - newsletter (22 July, Dubai)

Two ways this is delivered:

## 1. In Mailchimp (already saved to the account)
A campaign plan **"Galtech Design Tools Dealer Training"** was created and saved to the Mailchimp account (folder of the same name). It contains the invitation email plus follow-up and social touches across 8 to 22 July. The primary **invitation email** was corrected to the real details:
- In-person, Dubai only. Wednesday 22 July 2026, 10:00 to 15:00 (GST).
- Morning / afternoon agenda, lunch and networking, seats limited.
- Every button links to galtechtrading.com ("Register at galtechtrading.com").
- No em-dashes.

Note: Mailchimp generated the layout with **template placeholder images** (stock). Swap them for the real screenshots in `images/` using the Mailchimp editor (drag the image block, upload), or use the ready HTML below.

## 2. Ready-to-paste HTML (recommended for the screenshots)
`newsletter.html` is a self-contained, email-safe newsletter that already uses the real tool screenshots. To use it in Mailchimp: Create > Email > **Code your own > Paste in code**, and paste the file. Images are hosted from this repo (raw GitHub URLs), so they load without any upload.

- 600px, table-based, inline CSS, web-safe fonts. Renders in Gmail / Outlook / Apple Mail.
- `images/` holds the hosted screenshots (email-optimized JPGs) and the logo.
- Merge tags `*|ARCHIVE|*`, `*|UNSUB|*`, `*|UPDATE_PROFILE|*` are in the footer for Mailchimp.

Screenshots: 3D sound test, SPL coverage heatmap, 3D model, connection schedule. Captured from the Galtech Design Tools screen recording. No em-dashes per house style.
