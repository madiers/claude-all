# Galtech — Content

All marketing content, organised by channel.

```
Content/
├── blog/          brand-story posts for galtechtrading.com/blog
│                  one folder per post: article.md + images/ (16:9 cards)
├── newsletters/   email campaigns (HTML + assets)
├── instagram/     IG carousels & posts (per-campaign: 4:5 / 1:1 video + caption.txt)
├── linkedin/      LinkedIn films & posts (1:1 / 16:9 + caption.txt)
└── _shared/       shared brand assets (InfoComm badge, references)
```

- **Source brand imagery** (product renders, scraped photos) lives in `../Assets/<brand>/`.
- **Raw data / CMS exports** (CSVs, product-photo dumps) belong in `../Sources/` (pending repo cleanup — ask before moving).

Each blog post folder is self-contained (article + images) so it drops straight into Framer.
