# Neuphonix Mk2

**Slug:** neuphonix-mk2
**Subtitle:** Krix's flagship floorstanding loudspeaker
**Brand:** krix
**Category:** floorstanding
**Source:** https://www.krix.com.au/product/neuphonix-mk2

## Description
The Neuphonix Mk2 is Krix's reference floorstander, a six-driver three-way design built around four custom 130mm bass drivers with oversized magnets, a dedicated 130mm midrange, and a ring-radiator tweeter. An extensive crossover of low-tolerance, high-grade components delivers an extended response out to 40kHz.

It is intended as both a high-fidelity 2-channel speaker and the front-left/right anchor of a Krix surround system.

**Key features**

- Six-driver, three-way reference floorstander
- Four 130mm bass drivers, 130mm midrange and ring-radiator tweeter
- Dual-chamber enclosure with sealed midrange and bass-reflex main chamber

## Specifications

- **Configuration:** 6-driver, 3-way
- **Bass drivers:** 4 x 130mm (5-inch) coated paper cone
- **Midrange:** 130mm (5-inch) coated paper, copper shorting ring
- **Tweeter:** 26mm dual-concentric ring radiator with waveguide centre plug
- **Frequency response:** 30Hz - 40kHz (in room)
- **Power handling:** 50-300 Watts RMS recommended
- **Sensitivity:** 90dB at 2.83V/1m
- **Impedance:** Nominally 6 Ohms (minimum 4.9 Ohms)
- **Dimensions:** 1046mm H x 225mm W x 405mm D
- **Weight:** 30kg each
