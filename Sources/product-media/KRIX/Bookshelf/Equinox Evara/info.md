# Equinox Evara

**Slug:** equinox-evara
**Subtitle:** Big sound, small footprint - contemporary-finish Equinox
**Brand:** krix
**Category:** bookshelf
**Source:** https://www.krix.com.au/evara-range

## Description
The Equinox Evara is a redesigned, contemporary-finish edition of the Equinox bookshelf, with modern cabinet finishes and precision magnetic grilles. Krix states it delivers the same acoustic performance as the Equinox Mk5, built around a 130mm bass/midrange driver and a 26mm dual-concentric tweeter with waveguide centre plug.

**Key features**

- Contemporary-finish edition of the Equinox bookshelf
- 130mm bass/midrange and 26mm dual-concentric tweeter
- Precision magnetic grilles; performance matches the Equinox Mk5

## Specifications

- **Drivers:** 130mm bass/midrange + 26mm dual-concentric tweeter
- **Frequency response:** 45Hz - 40kHz
- **Sensitivity:** 88dB
