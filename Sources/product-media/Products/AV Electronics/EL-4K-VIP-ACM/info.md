## Description
### Integrate 4K Video over IP into your Nice smart home control system.

The Nice EL-4K-VIP-ACM Advanced Control Module brings the Nice Premium Video over IP (VIP) platform together, distributing HDMI video across a 1Gb network switch using visually lossless technology. Built-in Nice drivers simplify installation and remove the need to understand complex network infrastructure.

- Designed to work with the Nice smart home control and automation platform
- Optional web interface module with drag-and-drop source selection and video preview when used without a Nice control system
- Advanced signal management for independent routing of IR, RS-232, USB/KVM, audio and video

**Networking and control**

- Two RJ45 LAN connections bridge an existing network to the VIP video distribution network, separating traffic for better performance
- Independent IP address per LAN connection with simplified TCP/IP, RS-232 and IR control of the VIP system
- Powered via PoE from a PoE switch, with an optional local 12V supply
- iOS and Android app control plus 3rd-party drivers for all major home control brands

Auto system configuration and no advanced network setup make the EL-4K-VIP-ACM a straightforward way to deploy whole-home 4K video distribution.
