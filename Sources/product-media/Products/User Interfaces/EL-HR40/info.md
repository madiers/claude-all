## Description
### The remote control experience, redefined.

The HR40 Remote Control is a full-fledged control interface that lets you answer the front door with video, view surveillance cameras, or communicate with other interfaces using intercom, all from a 3.1" high resolution touchscreen. With swipe, scroll and touch controls, the HR40 is intuitive and provides an unparalleled user experience for control of media, lighting, climate, security, surveillance, and more.

- 3.1" LED backlit capacitive touchscreen with 480 x 800 resolution
- Integrated intercom and video doorbell answering plus surveillance monitoring
- Integrated voice control and backlit buttons that wake on motion or button press

**Built for easy deployment**

- Wi-Fi connectivity for extended range and wireless configuration
- Direct IR control without IR emitter cables and a remote finder feature
- Magnetic charging base securely holds the remote in place

Wirelessly configured and personalized with interface templates, the HR40 can be quickly added to any Nice system for the most intuitive control.
