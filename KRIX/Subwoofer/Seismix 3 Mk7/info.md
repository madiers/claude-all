# Seismix 3 Mk7

**Slug:** seismix-3-mk7
**Subtitle:** Front-firing vented subwoofer with Krix-designed 275mm long-throw driver
**Brand:** krix
**Category:** subwoofer
**Source:** https://www.krix.com.au/product/seismix3-mk7

## Description
The Seismix 3 Mk7 is a front-firing, vented subwoofer featuring a Krix-designed 275mm long-throw bass driver developed for high-level low-frequency reinforcement. Enhanced geometry within the magnet structure increases linear cone travel by 30% and allows superior driver control.

A built-in high-performance class D amplifier delivers efficient output with lower power consumption.

**Key features**

- Krix-designed 275mm long-throw bass driver
- Magnet geometry increases linear cone travel by 30%
- Built-in high-performance class D amplifier

## Specifications

- **Driver:** 275mm (11-inch) doped paper cone, 50mm (2-inch) voice coil, vented magnet
- **Amplifier power:** 300 Watts RMS
- **Frequency response:** 22Hz - 200Hz
- **Enclosure:** Bass reflex, front vented
- **Dimensions:** 450 x 360 x 410mm (H x W x D)
- **Weight:** 18kg
