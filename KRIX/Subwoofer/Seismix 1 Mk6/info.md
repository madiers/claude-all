# Seismix 1 Mk6

**Slug:** seismix-1-mk6
**Subtitle:** Compact down-firing subwoofer with 200mm woofer and class D amp
**Brand:** krix
**Category:** subwoofer
**Source:** https://www.krix.com.au/product/seismix1-mk6

## Description
The Seismix 1 Mk6 is a compact down-firing subwoofer combining a 200mm doped-paper-cone woofer with a high-quality class D amplifier. It uses a bass reflex, down-firing-vent enclosure for deep bass in a small footprint.

**Key features**

- 200mm doped paper cone woofer in a compact cabinet
- High-quality built-in class D amplifier
- Bass reflex, down-firing vent enclosure

## Specifications

- **Driver:** 200mm (8-inch) doped paper cone, 38mm voice coil, vented magnet
- **Amplifier power:** 350 Watts RMS, 700 Watts maximum instantaneous
- **Frequency range:** 25Hz - 200Hz (in room)
- **Output:** 116dB maximum SPL (in room)
- **Inputs:** Stereo line-level RCA
- **Enclosure:** Bass reflex, down-firing vent
