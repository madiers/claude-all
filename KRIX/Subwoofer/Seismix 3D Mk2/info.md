# Seismix 3D Mk2

**Slug:** seismix-3d-mk2
**Subtitle:** Down-firing subwoofer with Krix-designed 275mm long-throw driver
**Brand:** krix
**Category:** subwoofer
**Source:** https://www.krix.com.au/product/seismix-3d-mk2

## Description
The Seismix 3D Mk2 is a down-firing subwoofer featuring a Krix-designed 275mm long-throw bass driver developed for high-level low-frequency reinforcement. Enhanced magnet geometry increases linear cone travel by 30% for superior driver control, and a built-in high-performance class D amplifier provides efficient output with lower power consumption.

Power features on/off signal sensing with a 15-minute delay before standby, and continuously variable 0-180 degree phase select.

**Key features**

- Krix-designed 275mm long-throw down-firing driver
- Magnet geometry increases linear cone travel by 30%
- Signal-sensing power and continuously variable phase control

## Specifications

- **Driver:** Nominal 275mm (11-inch) doped paper cone, 50mm voice coil, vented magnet
- **Amplifier power:** 300 Watts RMS
- **Frequency response:** 22Hz - 200Hz
- **Output:** 122dB maximum SPL (in room)
