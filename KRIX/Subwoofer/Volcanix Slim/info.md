# Volcanix Slim

**Slug:** volcanix-slim
**Subtitle:** Slim home-cinema subwoofer for behind acoustically transparent screens
**Brand:** krix
**Category:** subwoofer
**Source:** https://www.krix.com.au/product/volcanix-slim

## Description
The Volcanix Slim uses the same bass driver and class D amplifier as the award-winning Volcanix, but is redesigned to fit behind acoustically transparent screens or be mounted into shallow false baffle walls. It uses two large down-firing ports giving a 40% larger vent area than the standard Volcanix, for improved bass performance at higher volumes.

A front-mounted control panel with LED display allows easy adjustment, and proprietary Krix rubber feet improve acoustic isolation.

**Key features**

- Same 305mm driver and class D amp as the Volcanix in a slim cabinet
- Dual down-firing ports with 40% larger vent area
- Front-mounted control panel with LED display

## Specifications

- **Driver:** 305mm bass driver with 50mm long throw voice coil
- **Amplifier:** Built-in ICEpower class D, 450 Watts RMS
- **In-room response:** 15Hz - 200Hz
- **Output:** 125dB maximum SPL (in room)
- **Dimensions:** 630mm H x 500mm W x 309mm D
