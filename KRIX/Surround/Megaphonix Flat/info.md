# Megaphonix Flat

**Slug:** megaphonix-flat
**Subtitle:** Flat-baffle high-output on-wall main/surround speaker
**Brand:** krix
**Category:** surround
**Source:** https://www.krix.com.au/product/megaphonix-flat

## Description
A flat-baffle version of the Megaphonix for dedicated home cinema, using the same high power-handling, high-sensitivity 10-inch driver complement for full-impact cinema sound.

**Key features**

- Flat-baffle version of the Megaphonix
- Same high-output 10-inch driver complement
- Ferro-fluid cooled tweeter on 90 x 40 short-throw waveguide

## Specifications

- **Drivers:** 255mm (10-inch) paper cone, 50mm voice coil + 26mm doped fabric dome on 90x40 waveguide
- **Frequency range:** 40Hz - 20kHz (in room)
- **Power handling:** 50-250 Watts RMS
- **Sensitivity:** 95dB at 2.83V
- **Crossover point:** 1.8kHz
- **Dimensions:** 885mm H x 390mm W x 162mm D
