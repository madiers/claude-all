## Description
### Add Nice multi-zone control to standard amplifiers and AVRs.

The Nice EL-IPD-PRE-MSI Multi Zone Preamp Audio Matrix can be used in a standalone configuration with standard amplifiers or AVRs, or with other amplifiers and pre-amps within the Nice IP audio distribution family by adding the optional Dante audio networking card. In standalone mode, when paired with external amplifiers, it supports up to 22 input sources (6 digital, 16 mono / 8 stereo analog RCA, and 1 stereo 3.5mm doorbell input from a Nice System Controller).

- 6 stereo / 12 mono pre-amp zones
- Adds Nice zone control to any amplifier
- 3 optical, 3 coax, and 8 stereo / 16 mono analog inputs

**DSP and expansion**

- DSP with 5-band EQ, lip-sync correction, and adjustable crossover for each zone
- Optional Network Audio Card adds Dante audio networking
- Dedicated 3.5mm stereo doorbell input

Nice IP-enabled audio distribution scales from a single chassis to a decentralized multi-chassis, multi-source implementation, meeting the needs of projects up to 64 individual zones.
